# Настройка отправки email через Mail.ru

## Что нужно для настройки:

1. **Email адрес** от Mail.ru (например: `yourname@mail.ru`)
2. **Пароль приложения** (НЕ обычный пароль от почты!)

## Как получить пароль приложения для Mail.ru:

1. Войдите в свой аккаунт Mail.ru
2. Перейдите в **Настройки** → **Пароли и доступ** → **Пароли приложений**
3. Нажмите **Создать пароль приложения**
4. Выберите название (например: "Веб-приложение")
5. Скопируйте сгенерированный пароль (он будет показан только один раз!)

## Настройка в проекте:

### Вариант 1: Через файл .env (рекомендуется)

Создайте файл `.env` в корне проекта со следующим содержимым:

**Для порта 587 с STARTTLS (рекомендуется):**
```env
MAIL_PROVIDER=mailru
MAIL_PORT=587
MAIL_USERNAME=yourname@mail.ru
MAIL_PASSWORD=ваш_пароль_приложения
MAIL_DEFAULT_SENDER=yourname@mail.ru
```

**Для порта 465 с SSL:**
```env
MAIL_PROVIDER=mailru
MAIL_PORT=465
MAIL_USERNAME=yourname@mail.ru
MAIL_PASSWORD=ваш_пароль_приложения
MAIL_DEFAULT_SENDER=yourname@mail.ru
```

**Важно:** 
- `MAIL_USERNAME` - ваш полный email адрес
- `MAIL_PASSWORD` - пароль приложения (НЕ обычный пароль!)
- `MAIL_DEFAULT_SENDER` - должен совпадать с `MAIL_USERNAME`
- По умолчанию используется порт 587 с STARTTLS (если `MAIL_PORT` не указан)

### Вариант 2: Через переменные окружения системы

Установите переменные окружения в системе:
- `MAIL_PROVIDER=mailru`
- `MAIL_USERNAME=yourname@mail.ru`
- `MAIL_PASSWORD=ваш_пароль_приложения`
- `MAIL_DEFAULT_SENDER=yourname@mail.ru`

## Проверка работы:

После настройки перезапустите приложение и попробуйте зарегистрироваться. 
Если все настроено правильно, на указанный email придет письмо с подтверждением.

## Режим отладки:

Если email не настроен, ссылка для подтверждения будет выводиться в консоль сервера.

## Проблемы:

- **Не приходят письма?** Проверьте папку "Спам"
- **Ошибка авторизации?** Убедитесь, что используете пароль приложения, а не обычный пароль
- **Письма не отправляются?** Проверьте, что в `.env` указан правильный `MAIL_PROVIDER=mailru`
