## 1. Проверка пароля приложения

**ВАЖНО:** Mail.ru требует пароль приложения, а не обычный пароль от почты!

### Как создать пароль приложения:

1. Войдите в Mail.ru
2. Перейдите: **Настройки** → **Пароли и доступ** → **Пароли приложений**
3. Нажмите **"Создать пароль приложения"**
4. Выберите название (например: "Веб-приложение")
5. **Скопируйте сгенерированный пароль** (он показывается только один раз!)

### Обновите `.env`:

```env
MAIL_PASSWORD=ваш_новый_пароль_приложения
```

## 2. Проверка файрвола и антивируса

SMTP порты (587, 465) могут блокироваться:

- **Windows Firewall**: Разрешите исходящие соединения на порты 587 и 465
- **Антивирус**: Временно отключите для проверки
- **Корпоративный файрвол**: Обратитесь к администратору

## 3. Альтернативные настройки

### Вариант 1: Порт 587 с STARTTLS (текущий)
```env
MAIL_PROVIDER=mailru
MAIL_PORT=587
MAIL_SECURE=false
MAIL_REQUIRE_TLS=true
```

### Вариант 2: Порт 465 с SSL
```env
MAIL_PROVIDER=mailru
MAIL_PORT=465
MAIL_SECURE=true
MAIL_REQUIRE_TLS=false
```

## 4. Режим отладки

Если письма не отправляются, включен режим отладки. Ссылки для подтверждения будут выводиться в консоль сервера.

Для включения/выключения в `.env`:
```env
MAIL_DEBUG_MODE=true   # Включить режим отладки
MAIL_DEBUG_MODE=false  # Выключить (реальная отправка)
```

## 5. Тестирование подключения

Запустите тестовый скрипт:
```bash
python test_mailru_detailed.py your_email@mail.ru
```

## 6. Альтернативные решения

Если SMTP не работает из-за блокировки провайдера:

1. **Использовать внешний SMTP сервис:**
   - Mailgun
   - SendGrid
   - Amazon SES

2. **Использовать другой почтовый провайдер:**
   - Gmail (требует пароль приложения)
   - Yandex (требует пароль приложения)

## 7. Проверка логов

При запуске Flask приложения проверяйте консоль на наличие ошибок:
- `Connection unexpectedly closed` - проблема с подключением
- `Authentication failed` - неверный пароль
- `[Errno 2] No such file or directory` - проблема с SSL/файрволом

## Текущие настройки

Проверьте файл `.env`:
- `MAIL_USERNAME` должен быть полным email адресом
- `MAIL_PASSWORD` должен быть паролем приложения
- `MAIL_DEFAULT_SENDER` должен совпадать с `MAIL_USERNAME`
